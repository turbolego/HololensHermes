Privacy Policy for HololensHermes

Last updated: October 26, 2026

Current prototype behavior

HololensHermes is an incomplete HoloLens 1 prototype. Its Telegram and Hermes service wrappers are not connected to the running interaction flow. The app does not currently capture or upload photos or voice recordings.

  • The app requests a coarse location estimate through Windows location services and keeps the latest estimate in memory. The running app does not currently send this estimate to Hermes.
  • Spatial mapping and head tracking use HoloLens sensors. The app does not upload spatial meshes.
  • The package declares webcam and microphone capabilities, but the app has no photo-capture or voice-recording/upload flow. Speech feedback is synthesized locally on the device.
  • The package declares internet access. The Telegram and Hermes service wrappers can send HTTPS requests when called; they are not currently invoked by the running interaction flow.

Credentials and network services

The Telegram prototype can store a Telegram username, password, and bot token in the Windows Credential Vault. If its send method is invoked, the bot token is sent as part of the HTTPS request to Telegram and the message is sent to a chat ID already present in the vault. The current app has no connected credential or chat setup flow. The Hermes prototype can send goal text and optional coarse location fields to a configured Hermes endpoint when its methods are invoked.

Future features

Photo upload, voice recording/upload, inbound agent replies, and a connected conversation flow are not implemented. Before enabling them, this policy must be updated to identify the receiving services, data sent, retention, and user consent choices. Do not send sensitive information or production credentials through this prototype.
